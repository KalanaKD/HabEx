# Habit + Expense Tracker — Project Brief

## Goal
A personal, single-user Android app (built and installed as an APK) that combines:
1. A gamified habit/task tracker (points, streaks, levels)
2. An expense tracker with category budgeting

Offline-first. No backend server for v1 — all data stays on the device in a local SQLite database.

## Tech stack (decided — do not re-litigate)
- Frontend: React 18 + TypeScript + Vite
- Styling: Tailwind CSS
- Charts: Recharts
- Native wrapper: Capacitor (Android target)
- Local database: SQLite via `@capacitor-community/sqlite`
  (falls back to `jeep-sqlite`/IndexedDB in the browser during development, uses native SQLite on-device once built as an APK)
- App lock: Capacitor biometric/PIN plugin (added in the later phase, not blocking core features)
- No cloud, no auth server, no multi-user support in v1.

## Database schema (SQLite)
```sql
CREATE TABLE habits (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  type TEXT NOT NULL CHECK(type IN ('habit','daily','todo')),
  difficulty TEXT NOT NULL CHECK(difficulty IN ('trivial','easy','medium','hard')),
  base_points INTEGER NOT NULL,
  schedule TEXT,          -- 'daily' | 'weekdays' | 'weekly'
  science_tag TEXT,       -- e.g. 'Fogg tiny habit', 'gratitude RCT'
  active INTEGER DEFAULT 1,
  created_at TEXT NOT NULL
);

CREATE TABLE habit_logs (
  id TEXT PRIMARY KEY,
  habit_id TEXT NOT NULL REFERENCES habits(id),
  completed_on TEXT NOT NULL,     -- date
  points_earned INTEGER NOT NULL,
  streak_at_time INTEGER NOT NULL
);

CREATE TABLE categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  budget_group TEXT NOT NULL CHECK(budget_group IN ('needs','wants','savings'))
);

CREATE TABLE expenses (
  id TEXT PRIMARY KEY,
  category_id TEXT NOT NULL REFERENCES categories(id),
  amount REAL NOT NULL,
  spent_on TEXT NOT NULL,
  note TEXT,
  is_recurring INTEGER DEFAULT 0
);

CREATE TABLE budgets (
  id TEXT PRIMARY KEY,
  category_id TEXT NOT NULL REFERENCES categories(id),
  month TEXT NOT NULL,       -- 'YYYY-MM'
  limit_amount REAL NOT NULL
);

CREATE TABLE goals (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  target_amount REAL NOT NULL,
  current_amount REAL DEFAULT 0
);
```

## Points / level formulas
```
base_points   = { trivial: 5, easy: 10, medium: 20, hard: 35 }
streak_bonus  = min(streak_days * 2, 30)
points_earned = base_points[difficulty] + streak_bonus
level         = floor(sqrt(total_points / 100))
```

## Money rules to encode
- Every category tagged `needs` / `wants` / `savings` — dashboard compares actual ratio to the 50/30/20 target.
- Zero-based monthly budgeting: user allocates `limit_amount` per category per month until nothing is left unassigned.
- Overspend flag: if this month's spend in a category > 1.3x the trailing 3-month average for that category, surface a warning (simple moving-average check, no ML needed).

## Build order — build each phase as a working, testable slice before moving on
1. **Scaffold**: Vite + React + TS + Tailwind. Install Capacitor, `npx cap add android`, confirm an empty APK builds and installs on a device/emulator.
2. **Data layer**: `db.ts` — initialize SQLite, run the schema above, basic CRUD smoke test.
3. **Habit tracker**: CRUD for habits, "mark complete" action that writes a `habit_log` row, computes points via the formula, and updates the running streak.
4. **Habit dashboard**: streak calendar heatmap, XP/level widget, weekly completion %.
5. **Expense tracker**: CRUD for expenses and categories, recurring-expense handling.
6. **Budgets**: monthly allocation UI (zero-based), the overspend check above.
7. **Expense dashboard**: category pie chart, budget-vs-actual bar chart, needs/wants/savings ratio vs. 50/30/20 target.
8. **Today screen**: unify habit + expense summaries into one view.
9. **App lock**: biometric/PIN via Capacitor plugin.
10. **Release build**: signed APK for install on device.

## Habit template library (seed data, each tagged with its source)
- Meditation (Fogg tiny-habit fallback: 3 breaths minimum)
- Metta/loving-kindness meditation
- Gratitude journal — 3 items/day (gratitude-intervention meta-analyses show a small-to-moderate positive effect on wellbeing)
- Sleep consistency
- Movement/exercise
- Screen-time limit

## Non-goals for v1
- No multi-user accounts, no cloud sync, no social/party features (Habitica-style guilds are explicitly out of scope).
- Keep the UI functional and minimal — this is a personal tool, not a polished commercial product.
